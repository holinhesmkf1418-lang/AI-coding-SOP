# AI编程规划工作台 — 原子化开发计划 v2.0

> 每个 Task = 2~4小时可完成的原子单元
> 四阶段：基建数据模型 → 后端API → 前端交互 → 测试联调
> 状态标记：[ ] 待执行  [-] 进行中  [x] 已完成

---

## 预执行自检报告

1. **反巨石**：WorkbenchView易成God Object，强制拆为StepIndicator、ChatPanel、OutputEditor、ToolBar四子组件+composable抽离
2. **反硬编码**：模型标识/步骤名称/状态枚举全走数据库配置，代码只认UUID
3. **数据完整性**：edited_output为空fallback到ai_output，Pydantic校验阻断脏数据
4. **并发风险**：SSE用httpx.AsyncClient确保非阻塞，SQLite开WAL模式
5. **解耦**：后端统一chat completion接口，前端只发{model_id, messages}，适配器在后端
